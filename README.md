# Room-No-518

A modern, gamified touch-typing web application with speed-responsive tier transformations, bilingual English & Bangla Avro modes, and an AI-powered Weakness Workout engine, built with **React**, **Vite**, and **Tailwind CSS v4**.

---

## 🌟 Key Features

- **Full 685-Lesson Touch Typing Curriculum**: 8 progressive stages from Home Row fundamentals to Grandmaster fluency.
- **🇧🇩 Bangla Avro (অভ্র) Mode**: 80 progressive lessons with real-time phonetic transliteration.
- **🎯 Weakness AI Adaptive Engine**: 10-finger latency tracking, identifying slow fingers and tricky words to synthesize custom real-word paragraph workouts.
- **Interactive Curriculum Map**: Numbered milestone grid, search/jump bar, and star progress tracking.
- **Speed-Responsive Dynamic Avatars (3, 5, 7, 9, 10+ WPM)**:
  - **Tier 1**: < 3 WPM / Typo State
  - **Tier 2**: 3 - 4 WPM (Stressed State)
  - **Tier 3**: 5 - 6 WPM (Initial State)
  - **Tier 4**: 7 - 8 WPM (Glamour Star)
  - **Tier 5**: 9 - 10+ WPM (Max Level 👑)
- **High-Performance Typing Interface**:
  - Classic serif typography with high-contrast text and blue cursor indicator.
  - Virtual Keyboard with color-coded finger placement columns and hand overlays.
  - Natural spacebar handling with zero latency.
- **Custom Photo Manager**: Upload or customize tier photos with local browser persistence (`localStorage`).
- **Web Audio Synthesizer**: Realistic mechanical keyboard click sounds, combo chimes, and level-up fanfares.
