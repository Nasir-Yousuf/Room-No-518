# Room-No-518

A modern, gamified typing web application inspired by **Typing Club** with speed-responsive tier transformations, built with **React**, **Vite**, and **Tailwind CSS v4**.

---

## 🌟 Key Features

- **Full 1 to 500 Curriculum**: 8 progressive stages from Home Row fundamentals to Grandmaster typing.
- **Interactive 500-Lesson Map**: Numbered milestone grid, search/jump bar, and star progress tracking.
- **Speed-Responsive Dynamic Avatars (3, 5, 7, 9, 10+ WPM)**:
  - **Tier 1**: < 3 WPM / Typo State
  - **Tier 2**: 3 - 4 WPM (Stressed State)
  - **Tier 3**: 5 - 6 WPM (Initial State)
  - **Tier 4**: 7 - 8 WPM (Glamour Star)
  - **Tier 5**: 9 - 10+ WPM (Max Level 👑)
- **Authentic Typing Club Interface**:
  - Classic serif typography with high-contrast text and blue cursor indicator.
  - Virtual Keyboard with color-coded finger placement columns, hand overlays, road sign scenery, and yellow taxi.
  - Natural spacebar handling with zero latency.
- **Custom Photo Manager**: Upload or customize tier photos with local browser persistence (`localStorage`).
- **Web Audio Synthesizer**: Realistic mechanical keyboard click sounds, combo chimes, and level-up fanfares.
